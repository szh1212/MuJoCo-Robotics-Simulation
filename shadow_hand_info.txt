2. NAMING CONVENTION
==========================================

WR = Wrist
TH = Thumb
FF = First Finger (Index)
MF = Middle Finger
RF = Ring Finger
LF = Little Finger

==========================================
3. PARAMETER EXPLANATION
==========================================

Joint:
Defines the relative motion between rigid bodies.

Actuator:
Generates forces or torques through a transmission.

Control Range:
The permitted range of actuator control input.

Transmission:
0 = Joint transmission
3 = Site transmission

Gain:
The actuator gain parameter (gainprm[0]).
Its physical meaning depends on actuator configuration.

qpos:
Generalized position coordinates of the robot.

ctrl:
Control input sent to the actuators.

==========================================
4. NOTES
==========================================

1. Shadow Hand contains 25 joints and 20 actuators.

2. Some joints have coupled motion.

3. Transmission = 0 indicates joint transmission.

4. Transmission = 3 indicates site transmission.

5. Control range is not necessarily the joint angle range.

6. Gain affects actuator output, but should not be
   interpreted as motor torque without examining
   the actuator configuration.
